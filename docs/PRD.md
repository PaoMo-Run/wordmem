# 产品需求文档 (PRD) - Lexicon 离线英语词库

> 版本: 1.0  
> 日期: 2026-08-12  
> 平台: Android only (minSdk 26)  
> 定位: 个人使用，无商业化需求

---

## 1. 产品概述

### 1.1 产品名称

Lexicon（项目代号，最终名称由开发者自定）

### 1.2 产品定位

一款完全离线的个人英语单词学习与复习 App。以 FSRS 间隔重复算法为核心，帮助用户高效记忆英语词汇。所有数据存储在设备本地，不联网、不登录、不上传任何信息。

### 1.3 核心价值

| 价值点 | 说明 |
|--------|------|
| 隐私优先 | 不申请网络权限，不嵌入任何分析 SDK，学习数据永不离开设备 |
| 科学复习 | 采用 FSRS-5 算法，基于记忆模型动态调整复习间隔 |
| 离线词典 | 内置 ECDICT 词典子集，添加单词时自动匹配音标与释义 |
| 个人定制 | 可改写释义、添加备注与标签，打造个人化词库 |

### 1.4 约束条件

- 目标平台：Android 8.0 (API 26) 及以上
- 单用户、单设备使用，不支持多设备同步
- 不包含任何网络通信功能
- 不包含 AI、在线词典、在线例句等功能
- 以 APK 形式分发，无需上架应用商店

## 2. 用户画像与使用场景

### 2.1 用户画像

**英语学习者**：有日常英语阅读/学习需求，希望系统化管理生词并通过科学复习长期记忆。注重隐私，不希望学习数据被收集。技术能力中等，能自主安装 APK。

### 2.2 核心使用场景

| 编号 | 场景 | 描述 |
|------|------|------|
| S1 | 单词添加 | 阅读英文文章时遇到生词，打开 App 输入单词，从词典匹配结果中选择释义，添加到个人词库 |
| S2 | 批量导入 | 粘贴一段英文文本，App 自动分词并匹配词典，用户勾选需要学习的单词批量导入 |
| S3 | 日常复习 | 每天固定时间打开 App，查看今日待复习单词，逐张卡片回忆并评分 |
| S4 | 词库管理 | 按标签、掌握状态、收藏等条件筛选和浏览已添加的单词 |
| S5 | 搜索查找 | 通过英文单词或中文释义模糊搜索个人词库中的单词 |
| S6 | 数据备份 | 定期导出词库备份文件到本地存储，防止数据丢失 |
| S7 | 词形查找 | 输入 "running" 能匹配到原型 "run" 的释义 |

## 3. 功能需求

优先级定义：
- **P0**：MVP 必须包含，缺失则产品不完整
- **P1**：MVP 应包含，显著提升体验
- **P2**：v2 及以后迭代

### 3.1 词典与单词管理

#### FR-1.1 新增单词 [P0]

**用户故事**：作为用户，我想输入一个英语单词后自动获取音标和释义，以便快速添加到词库。

**验收标准**：
- 输入英文单词（不区分大小写），点击查询
- 从内置词典匹配，返回音标、词性、中文释义
- 若匹配到多个义项，展示列表供用户选择
- 若词典无匹配，尝试词形反查（FR-1.6）
- 若仍无匹配，允许用户手动输入释义
- 选择义项后添加到个人词库，状态为"新词"
- 重复添加同一单词时提示"已在词库中"，可选择查看或覆盖

#### FR-1.2 个性化编辑 [P0]

**用户故事**：作为用户，我想修改单词释义、添加备注和标签，以便记录个人理解。

**验收标准**：
- 可改写词典释义（自定义释义优先于词典释义显示）
- 可添加中文备注（自由文本）
- 可添加标签（支持多个，逗号分隔输入）
- 可切换收藏状态
- 编辑保存后立即生效，不影响复习状态

#### FR-1.3 文本批量导入 [P0]

**用户故事**：作为用户，我想粘贴一段英文文本批量导入生词，以便高效扩充词库。

**验收标准**：
- 在添加单词页面提供"从文本导入"入口
- 用户粘贴英文文本（支持多行）
- App 使用正则分词，去重后批量匹配词典
- 展示候选列表：单词、音标、释义摘要、是否已在词库
- 用户勾选需要导入的单词
- 批量添加，每个单词使用词典第一条释义作为默认义项
- 导入完成后显示成功数量和跳过数量（已在词库中的）

#### FR-1.4 词库浏览与筛选 [P0]

**用户故事**：作为用户，我想按不同条件浏览和管理我的词库。

**验收标准**：
- 词库列表展示：单词、简要释义、标签、掌握状态图标
- 支持按以下条件筛选（可组合）：
  - 添加日期范围
  - 标签
  - 掌握状态（新词/学习中/已掌握）
  - 收藏状态
  - 待复习状态
- 支持按添加时间、字母顺序、下次复习时间排序
- 列表支持无限滚动加载

#### FR-1.5 本地搜索 [P0]

**用户故事**：作为用户，我想通过英文单词或中文释义搜索词库。

**验收标准**：
- 搜索栏支持英文和中文输入
- 英文搜索：匹配单词本身（FTS5 全文搜索，支持前缀匹配）
- 中文搜索：匹配自定义释义、备注、标签（LIKE 模糊匹配）
- 搜索结果实时更新（输入时触发，防抖 300ms）
- 搜索结果高亮匹配关键词

#### FR-1.6 词形反查 [P1]

**用户故事**：作为用户，我想输入 "running" 能找到 "run"，以便不用手动转换词形。

**验收标准**：
- 查询单词时，若精确匹配无结果，尝试词形反查
- 利用 ECDICT exchange 字段解析词形变化
- 反查成功时展示原型单词释义，标注词形关系（如"running 是 run 的现在分词"）
- 批量导入时同样支持词形反查

#### FR-1.7 单词详情 [P0]

**用户故事**：作为用户，我想查看某个单词的完整信息和学习记录。

**验收标准**：
- 展示：单词、音标、词性、完整释义
- 展示个人备注、标签、收藏状态
- 展示复习统计：复习次数、遗忘次数、下次复习日期、当前掌握状态
- 提供编辑入口

### 3.2 复习系统

#### FR-2.1 今日任务 [P0]

**用户故事**：作为用户，我想打开 App 就知道今天要做什么。

**验收标准**：
- 展示今日待复习单词数量
- 展示今日已新增单词数量
- 展示今日已完成复习数量和进度
- 提供"开始复习"按钮（有待复习单词时高亮）
- 提供"添加单词"按钮
- 无待复习时显示"今日复习已完成"鼓励信息

#### FR-2.2 复习卡片 [P0]

**用户故事**：作为用户，我想通过卡片形式复习单词，先回忆再看答案。

**验收标准**：
- 卡片正面：大字号展示英文单词 + 音标
- 点击卡片（或翻转按钮）揭示：中文释义 + 个人备注
- 卡片底部展示四档评分按钮
- 支持左右滑动切换上一张/下一张卡片
- 复习完所有待复习卡片后展示完成总结
- 复习过程中可跳过（不计入评分，稍后复习）

#### FR-2.3 复习评分 [P0]

**用户故事**：作为用户，我想根据自己的回忆情况评分，让算法调整复习间隔。

**验收标准**：
- 四档评分，严格映射 FSRS Rating：
  - "没想起来" -> Rating 1 (Again)
  - "想起来但困难" -> Rating 2 (Hard)
  - "正确" -> Rating 3 (Good)
  - "很轻松" -> Rating 4 (Easy)
- 评分后立即计算下次复习时间并更新卡片状态
- "没想起来"按钮必须有明显视觉区分（红色），防止误选
- 评分操作在数据库事务中完成，确保数据一致性
- 评分后显示下次复习间隔（如"下次复习：3天后"）

#### FR-2.4 新词首次复习 [P0]

**验收标准**：
- 新添加的单词立即安排一次短间隔复习（10 分钟后）
- 首次复习后交由 FSRS 决定后续间隔
- 新词在今日任务中计入"待复习"数量

### 3.3 统计

#### FR-3.1 学习统计 [P0]

**用户故事**：作为用户，我想查看自己的学习数据，了解进度和习惯。

**验收标准**：
- 展示以下指标：
  - 总词库数量
  - 今日新增 / 今日复习 / 待复习
  - 连续学习天数（streak）
  - 预计平均记忆率（基于 FSRS stability 计算）
- 展示近 7 天 / 30 天的新增和复习量趋势图（柱状图）
- 展示掌握状态分布（新词/学习中/已掌握 饼图）

#### FR-3.2 连续学习天数 [P0]

**验收标准**：
- 每日完成至少 1 次复习或新增 1 个单词记为"已学习"
- 连续学习天数 = 连续"已学习"的天数
- 展示当前连续天数和历史最长连续天数

### 3.4 设置

#### FR-4.1 复习参数设置 [P0]

**验收标准**：
- 目标记忆率：默认 90%，可调范围 80%-95%，步进 5%
- 修改后对所有后续排程生效
- 展示当前使用的 FSRS 参数来源（默认/已优化）

#### FR-4.2 提醒设置 [P0]

**验收标准**：
- 每日学习提醒：可开关，默认开启，默认时间 20:00
- 提醒时间可自定义（时间选择器）
- 待复习提醒：当有待复习单词且当天未复习时，在设定时间提醒
- 提醒内容："你有 N 个单词待复习" 或 "今天还没有学习，来添加新单词吧"
- 点击通知直接打开 App 今日页面

#### FR-4.3 外观设置 [P1]

**验收标准**：
- 深色模式：跟随系统 / 强制浅色 / 强制深色
- 默认跟随系统

#### FR-4.4 数据导入导出 [P0]

**验收标准**：
- 导出：生成 .zip 备份文件，包含个人词库数据库、FSRS 参数、manifest.json
- 导出前自动执行 WAL checkpoint 确保数据完整
- 导出文件保存到用户指定位置（通过系统文件选择器）
- 导入：选择 .zip 文件，验证 manifest.json 完整性（SHA-256 校验）
- 导入前提示"将覆盖当前词库数据"，需用户确认
- 导入后检查词典版本兼容性，不匹配时提示

#### FR-4.5 词典信息 [P1]

**验收标准**：
- 展示当前词典版本、词条数量、数据来源（ECDICT）、许可信息
- 展示个人词库统计数据

### 3.5 引导与空状态

#### FR-5.1 首次启动引导 [P1]

**验收标准**：
- 首次打开 App 时展示简要引导（3-4 屏滑动介绍）
- 介绍核心流程：添加单词 -> 复习 -> 评分
- 引导结束后进入今日页面
- 引导只展示一次（通过 SharedPreferences 标记）

#### FR-5.2 空状态 [P1]

**验收标准**：
- 今日页面无单词时：展示引导文案"还没有单词，点击下方按钮添加你的第一个单词"
- 词库页面无单词时：展示引导文案"词库还是空的，去添加单词吧"
- 统计页面无数据时：展示"添加单词并开始复习后，这里会展示你的学习数据"

### 3.6 数据安全

#### FR-6.1 数据库损坏检测 [P0]

**验收标准**：
- App 启动时执行 `PRAGMA quick_check` 检测数据库完整性
- 检测到损坏时：
  1. 尝试从最近一次自动备份恢复（如有）
  2. 若无备份或备份也损坏，提示用户手动导入备份文件
  3. 若用户无备份，保留词典数据，重置个人词库（记录错误日志）

#### FR-6.2 卸载前提醒 [P1]

**验收标准**：
- 由于 Android 无法拦截卸载操作，改为在设置页面显著位置提醒：
  "卸载 App 将删除所有学习数据，请先导出备份"
- 在导出功能旁边展示此提醒

## 4. 非功能需求

### 4.1 性能

| 指标 | 要求 |
|------|------|
| App 冷启动时间 | < 2 秒（到今日页面可交互） |
| 词典查询响应 | < 100ms（单次精确匹配） |
| 批量导入分词+匹配 | < 3 秒（500 词文本） |
| 词库列表加载 | < 200ms（首屏，1000 词） |
| 搜索响应 | < 150ms（防抖后） |
| 复习卡片切换 | < 50ms（动画流畅） |
| 数据库操作 | 均在后台 Isolate 执行，不阻塞 UI 线程 |

### 4.2 隐私

| 要求 | 实现方式 |
|------|----------|
| 不申请网络权限 | AndroidManifest.xml 中不声明 INTERNET 权限 |
| 不嵌入分析 SDK | pubspec.yaml 依赖树中无 analytics/crashlytics 等 |
| 不发起网络请求 | 代码中无 http/dio/socket 等网络库 |
| 数据仅本地存储 | 数据库存储在应用私有目录 |
| 验证机制 | 开发阶段抓包验证无网络请求；CI 依赖扫描 |

### 4.3 可靠性

| 要求 | 实现方式 |
|------|----------|
| 数据库事务完整性 | WAL 模式 + 事务包裹 + PRAGMA synchronous=NORMAL |
| 崩溃后数据一致 | 启动时 quick_check 检测 + 自动恢复 |
| 备份完整性 | SHA-256 校验 + WAL checkpoint |
| 提醒可靠性 | 使用 Android 精确闹钟 (setExactAndAllowWhileIdle) |

### 4.4 兼容性

| 要求 | 说明 |
|------|------|
| 最低 Android 版本 | Android 8.0 (API 26) |
| 目标 Android 版本 | Android 14 (API 34) |
| 架构支持 | arm64-v8a, armeabi-v7a, x86_64 |
| 屏幕适配 | 支持竖屏，适配 5.0-7.0 英寸手机 |
| 无障碍 | 支持系统字体缩放， TalkBack 兼容 |

## 7. 术语表

| 术语 | 说明 |
|------|------|
| FSRS | Free Spaced Repetition Scheduler，自由间隔重复调度器，一种基于记忆模型的复习算法 |
| FSRS-5 | FSRS 算法的第 5 版本，使用 19 个参数（权重）描述记忆模型 |
| 目标记忆率 | 期望在复习时能回忆起单词的概率，默认 90% |
| Stability (稳定性) | FSRS 中表示记忆强度的指标，稳定性越高，遗忘越慢 |
| Difficulty (难度) | FSRS 中表示单词难度的指标，影响复习间隔增长速度 |
| Rating | 复习评分，1=Again(没想起来) 2=Hard(困难) 3=Good(正确) 4=Easy(很轻松) |
| ECDICT | 开源英语词典数据库，MIT 许可，含 77 万词条 |
| FTS5 | SQLite Full-Text Search 5，全文搜索引擎 |
| WAL | Write-Ahead Logging，SQLite 日志模式，提高并发和崩溃安全性 |
| Isolate | Dart 的独立执行单元，类似于轻量级线程 |
