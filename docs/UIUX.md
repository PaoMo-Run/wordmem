# UI/UX 设计文档 - Lexicon 离线英语词库

> 版本: 1.0  
> 日期: 2026-08-12  
> 平台: Android only  
> 关联文档: PRD.md, Architecture.md

---

## 1. 设计原则

### 1.1 核心理念

**专注记忆，减少干扰。** 这是一款学习工具，不是社交媒体。每一屏的设计都应让用户更快地完成当前任务，而不是在 App 里逗留。

### 1.2 设计原则

| 原则 | 说明 | 设计指导 |
|------|------|----------|
| 内容优先 | 单词和释义是核心内容，必须最醒目 | 大字号、高对比度、充足留白 |
| 操作直觉 | 用户不需要思考下一步做什么 | 主要操作按钮固定在拇指可及区域 |
| 状态清晰 | 用户随时知道当前在做什么、还剩什么 | 进度指示、状态标签、剩余数量 |
| 克制装饰 | 不使用无意义的动画和装饰元素 | 仅在状态变化和页面切换时使用过渡动画 |
| 深色友好 | 默认支持深色模式，暗光环境下舒适 | 避免纯黑/纯白，使用深灰/浅灰层次 |

## 2. 信息架构

### 2.1 导航结构

```
底部导航栏（4 Tab）
│
├── 今日 (Today)
│   ├── 今日概览卡片
│   ├── 快捷操作（添加单词 / 开始复习）
│   └── 空状态引导
│
├── 词库 (Library)
│   ├── 搜索栏
│   ├── 筛选器（标签 / 状态 / 收藏 / 排序）
│   ├── 单词列表
│   └── [浮动按钮] 添加单词
│       ├── 手动输入
│       └── 从文本导入
│
├── 统计 (Stats)
│   ├── 概览数字（总词数 / 连续天数 / 记忆率）
│   ├── 近7天/30天趋势图
│   └── 掌握状态分布
│
└── 设置 (Settings)
    ├── 复习参数（目标记忆率）
    ├── 提醒设置（开关 / 时间）
    ├── 外观（深色模式）
    ├── 数据管理（导出 / 导入）
    └── 词典信息

独立页面（非 Tab）：
├── 添加单词页（全屏，从底部滑入）
├── 文本导入页（全屏）
├── 单词详情页（全屏）
└── 复习页（全屏，模态）
```

### 2.2 页面流转

```
今日 ──[开始复习]──> 复习页 ──[完成]──> 今日（刷新）
今日 ──[添加单词]──> 添加页 ──[保存]──> 今日（刷新）
词库 ──[点击单词]──> 详情页
词库 ──[浮动按钮]──> 添加页
词库 ──[添加页/文本导入]──> 文本导入页
详情 ──[编辑]──> 编辑模式
设置 ──[导出]──> 系统文件选择器
设置 ──[导入]──> 系统文件选择器 ──[确认]──> 导入结果
```

## 8. 动画规范

### 8.1 页面过渡

| 过渡 | 动画 | 时长 | 曲线 |
|------|------|------|------|
| Tab 切换 | 淡入淡出 | 150ms | easeInOut |
| 页面推入 | 从右滑入 | 300ms | easeOut |
| 模态弹出 | 从底部滑入 | 250ms | easeOut |
| 页面返回 | 向右滑出 | 250ms | easeIn |

### 8.2 元素动画

| 元素 | 动画 | 时长 | 曲线 |
|------|------|------|------|
| 复习卡片翻转 | Y轴 180度旋转 | 400ms | easeInOut |
| 评分后卡片退出 | 向左滑出 + 淡出 | 300ms | easeIn |
| 下一张卡片进入 | 从右滑入 + 淡入 | 300ms | easeOut |
| 进度条更新 | 宽度增长 | 300ms | easeOut |
| 列表项出现 | 淡入 + 向上偏移 | 200ms | easeOut |
| SnackBar 显示 | 从底部滑入 | 250ms | easeOut |

### 8.3 动画原则

- 所有动画时长控制在 150-400ms 之间
- 使用 Material 标准曲线（easeInOut, easeOut, easeIn）
- 避免弹跳效果（spring/bounce），保持克制
- 动画不能阻塞用户操作（评分后立即允许下一张卡片操作）
- 暗色主题下减少动画幅度，避免过度闪烁
