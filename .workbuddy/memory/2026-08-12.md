## 离线个人英语词库 App 方案审计

完成用户方案的系统性审计，输出 audit-report.md。

### 关键发现

**3 个阻断级风险：**
1. FTS5 在 Android 系统 SQLite 不可用 -> 必须用 sqlite3_flutter_libs 捆绑自定义 SQLite
2. FSRS 参数优化需 fsrs-rs-dart (Rust FFI)，纯 Dart 版 fsrs 包不支持优化
3. 数据库事务完整性缺失 -> 需 WAL 模式 + 事务包裹复习评分操作

**技术栈补充确认：**
- 词典数据源：ECDICT (MIT, 77万词条, 含音标/词性/释义/词形变化)
- 中文搜索：需 sqlite3_simple 分词器（FTS5 默认不支持中文）
- 状态管理：建议 Riverpod + go_router
- FSRS 优化触发条件：>= 1000 条复习记录后在 Isolate 中后台运行

**MVP 范围调整：**
- 新增 P0：文本批量导入、数据库损坏检测
- 新增 P1：空状态引导、词形反查
- 后移 v2：FSRS 参数本地优化（需足够数据）、日历热力图、词典包替换

## 产出 PRD + 架构文档 + UIUX 文档三件套

用户追加约束：Android only、个人使用、无商业化需求。基于此做出关键决策调整。

### 关键决策（Android-only + 个人使用）

1. **FSRS：MVP 用纯 Dart `fsrs` 包**（默认参数），v2 迁移 fsrs-rs-dart。免去 Rust 工具链/交叉编译，个人项目优先简化构建。
2. **中文搜索：LIKE 模糊查询**，不装 sqlite3_simple。个人词库千级数据量 LIKE 性能足够。
3. **英文搜索：FTS5 + unicode61 分词器**，通过 sqlite3_flutter_libs 捆绑含 FTS5 的 SQLite。
4. **事务安全：WAL + 事务包裹 + PRAGMA synchronous=NORMAL + 启动 quick_check + 自动恢复**。
5. **词典：ECDICT 高频子集约 3 万词 ~5MB，打包 assets 首次启动复制到文档目录**。
6. **仅 Android 3 ABI：arm64-v8a, armeabi-v7a, x86_64，无 iOS**。
7. **不声明 INTERNET 权限，CI 依赖扫描禁止网络库**。
