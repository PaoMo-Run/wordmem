## 四项需求方案分析（待用户确认后实施）

### 1. 导入覆盖/续写模式 + 导入不生效根因
- 根因（导入"部分不生效"）：`backup_repository.import()` 里 `_db.close()` 只 dispose 连接，但 WAL 模式下残留 `vocabulary.db-wal`/`-shm` 文件；直接 `writeAsBytes` 覆盖主 db 后重新 open，SQLite 会回放旧 wal 内容，导致数据错乱/旧数据复活。close 前未做 checkpoint。
- 方案：close 前 checkpoint + 删除 -wal/-shm 再写新库；import 成功后触发 wordListVersionProvider++ 刷新 UI
- 覆盖模式 = 修复后的整库替换；续写模式 = 不替换文件，读备份库逐条 INSERT（按 word 去重），review_logs 需重建 id 映射（外键）

### 2. 翻卡 bug + 动画
- 根因：`EnToZhCard` 无 key，换词时 Flutter 复用 State，`_revealed` 未重置 → 第二个词直接显示释义。ChooseWordCard(`_selected`)/DictationCard(`_controller.text`,`_answered`) 同样有状态残留
- 方案：所有测验卡片传 `ValueKey(wordId)` 强制重建；翻卡用 AnimationController + Transform(rotateY) 3D 翻转

### 3. 近义词多级匹配
- 现状：纯中文义项 Jaccard 重叠启发式，同义不同字漏报
- 方案：L0 WordNet 英文近义词(离线库) → L1 中文同义词词林/HowNet → L2 义项重叠兜底 → L3 用户黑名单，加权合并排序

### 4. 联网 + AI 陪练
- 现状：刻意离线（Manifest 无 INTERNET 权限、无 http 依赖、隐私文案"完全离线"）
- 方案：加 http 依赖 + INTERNET 权限；AiTutorService 抽象接口 + 可配置 endpoint/key/model；离线降级；MVP=AI 造句/对话陪练 + AI 出题
