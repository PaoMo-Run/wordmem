# 短文记忆测试 — 需求定稿（v2）

> 定稿时间：2026-08-17
> 状态：已确认方案，待实施（先于 P2/P3）
> 关联功能：今日短文 / 短文记忆库 / 词库分组

## 一、功能定位

基于「短文记忆库」中已保存的短文做**挖空默写测验**，检验用户对文中重点词与整体内容（实词）的记忆。三种难度递进，均为"整篇呈现、挖空作答"形式。

## 二、三种难度模式

| 模式 | 挖空对象 | 作答方式 | 检测目标 |
|------|---------|---------|---------|
| 复习模式 | 仅重点词（story.words 画线词） | 点击空格 → 弹出 4 选项选择 | 认识（再认） |
| 巩固模式 | 仅重点词 | 空格内直接输入单词 | 拼写（回忆） |
| 拓展模式 | 所有实词（动词/名词/形容词/副词），仅保留虚词/连接词 | 空格内直接输入 | 完整产出（最高难度） |

- 入口处弹**模式选择**（3 档，附说明文字）

## 三、答题交互（已确认：整篇呈现 + 做卷子式）

- 短文**全文一次呈现**，所有空格同时可见，用户可自由顺序作答、来回修改
- 复习模式：点空格 → 底部弹 4 选项 Chip
- 巩固/拓展：点空格 → 弹出输入框
- 已填的空显示答案，可点击重新作答
- **提交后统一判分**：错空原地标红 + 显示正确答案（做卷子式）
- 结束 → 结果页：得分 N/M、错题回顾、错词加入词库

## 四、错词加入词库（已确认：独立分组 + 用户自选）

**结果页交互**：
- 每个错词旁 checkbox，用户**逐词勾选**是否加入词库
- 底部「全部加入」一键勾选所有 +「加入选中的 N 个」执行
- 词已在词库（任意来源）→ 跳过并提示"已在词库"
- 加入的词标记来源为「短文测试」

## 五、词库分组（已确认：方案 B，按短文分组）

```
词库页筛选 chips： [全部] [手动添加] [短文测试 ▾]
                                    └─ 《My School Life》 （5 词）
                                       《A Day in the Park》（6 词）
                                       《Healthy Eating》  （4 词）
```

- 每个错词记录时**关联来源短文 story_id**，分组按短文折叠展开
- 便于体系化记忆：知道错词来自哪篇，可回看原文复习

## 六、数据模型

```sql
-- user_words 增加来源字段（迁移）
ALTER TABLE user_words ADD COLUMN source TEXT DEFAULT 'manual';
-- source: 'manual' 手动添加 | 'quiz' 短文测试错词

-- 测试记录表（新）
CREATE TABLE story_quiz_records (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  story_id INTEGER NOT NULL,          -- 关联短文
  mode TEXT NOT NULL,                 -- review/consolidate/extend
  total INTEGER NOT NULL,             -- 总空数
  correct INTEGER NOT NULL,           -- 答对数
  wrong_blanks TEXT DEFAULT '',       -- 错空明细（word:userAnswer:correct 逗号分隔）
  created_at TEXT NOT NULL
);
```

## 七、边界与容错

- 挖空为 0（短文全虚词/无重点词）→ 提示"该短文没有可挖空的词"，不进入答题
- 复习模式干扰项不足 3 个 → 用剩余重点词/词典近义顶替，仍不足则减少选项（3 选 1）
- 大小写容错：首字母大写差异算对，拼错才算错（与单词复习默写规则一致）
- 不挖多词空（保证答案唯一），单复数/时态按原文判定
- 测试记录**不回写 FSRS**（附加练习，不影响排程）

## 八、入口（3 处）

1. 记忆库 → 短文详情：「开始测试」按钮 → 模式选择
2. 今日短文 → 短文卡片操作行：「测试」按钮 → 模式选择
3. 测试历史：记忆库详情页底部展示该短文历史测试（得分/模式/日期）
